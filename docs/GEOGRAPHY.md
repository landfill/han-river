# 지리·모델 범위

이 앱은 **서울 한강을 모티프로 한 관람용 재구성**입니다. 실제 운항 상품, 항해용 지도, 측량 또는 디지털 트윈으로 사용하지 않습니다.

## 현재 장면의 좌표

- 모델 단위는 미터이며 X는 동쪽, Z는 남쪽, Y는 위쪽입니다.
- 여의도 쪽에서 원효대교를 지나 한강철교 쪽으로 향한다는 관람 순서를 사용합니다.
- 가상 항로는 X=-1150에서 X=1650까지 이동하며 8분입니다. 표기한 2.8km는 X 방향 모델 거리이며 실제 선착장 간 운항 거리의 검증값이 아닙니다. 완만한 굴곡을 포함한 실제 모델 곡선 길이는 이보다 조금 깁니다.
- 원효대교, 한강철교, 강변과 건축물 위치는 로컬 좌표로 단순 배치했습니다. WGS84를 변환한 결과가 아닙니다.
- 반복 교각 사이의 안전 여유와 강변 바깥으로 벗어나지 않는지는 이 모델 안에서 수치 검증합니다. 현실의 수심·교량 높이·운항 규정과는 별개입니다.

## 지리 검증의 상태

설정 중 OpenStreetMap 지도 API와 Wikipedia의 좌표 요청이 네트워크 프록시에서 HTTP 403으로 거부되었습니다. 해당 요청은 좌표나 실제 사진을 확보하지 못했습니다. 따라서 정밀 지리 검증을 완료했다고 주장하지 않습니다. GitHub의 참고 코드와 공개 모델 설명을 읽는 작업은 성공했습니다.

63빌딩의 금빛 슬래브, Parc1의 두 탑과 붉은 외부 구조, IFC의 고층 실루엣, 도로 교량과 철도 트러스의 차이를 절차적으로 표현했습니다. 외형·주변 건물·수목·지형은 단순화되어 있으며 실제 사진과의 정합 검증은 아직 수행하지 않았습니다.

## 정밀화 시 필요한 자료

서울 열린데이터광장, 국가공간정보와 OpenStreetMap 등의 공식·공개 데이터를 후보로 삼되, 각각의 다운로드·파생물·상업적 이용·표시 조건을 먼저 확인해야 합니다. 현 단계에서는 이들 기관의 데이터를 내려받거나 앱에 포함하지 않았습니다.

최소 검증 목록은 다음과 같습니다.

- 실제 선착장, 교량 중심선·상판 높이·교각 간격, 항로의 WGS84 좌표
- 강변 폴리곤과 수위 기준, 하천 구간의 실제 폭
- 63빌딩·Parc1·IFC의 좌표·높이·윤곽과 가시성
- 골든아워 날짜·서울 시간·태양 방위각과 고도
- 위치·시야각·초점거리·수위를 기록한 비교 사진

시간대 프리셋은 서쪽의 태양과 일관된 장면 조명을 사용하지만 특정 날짜의 천문 계산이나 실제 날씨·수위에 연결되지 않습니다.
