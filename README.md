# 한강유람 · Hangang Cruise

유람선 갑판에서 서울 한강을 관람하는 실시간 3D 웹 앱입니다. 한강을 단순화한 절차적 도시 모델과 두 개의 FFT 파도 스펙트럼, 대기 산란·구름, 수면 반사, 이동하는 선박을 하나의 장면으로 구성했습니다.

**현재 상태: 실행 가능한 관람 프로토타입입니다. 실사 수준의 서울 복원이나 실제 운항 항로의 정확성을 인증하는 제품은 아닙니다.** 정밀 GIS·사진측량 자산, 실제 사진과의 정합 검증, 물리 GPU의 성능 검증은 후속 작업입니다.

## 실행

Node.js 22.12 이상(이 환경: 24.19), npm이 필요합니다.

```sh
cd /workspace/han-river
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

개발 서버는 5173 포트에서 실행됩니다. 최신 Chrome 또는 Edge를 권장합니다. WebGPU를 먼저 확인하며, 사용 불가 또는 SwiftShader 등의 소프트웨어 어댑터에서는 WebGL2로 실행합니다. WebGL2도 사용할 수 없으면 오류 안내와 재시도를 표시합니다. 배포에는 HTTPS가 필요하며 localhost는 개발 보안 컨텍스트로 사용할 수 있습니다.

```sh
npm run build
npm run preview -- --port 4173
npm test
npm run test:browser
npm run test:production
```

브라우저 테스트에는 Chromium이 필요합니다. 기본 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다. 테스트가 자체 Vite 서버를 4175 포트에서 시작하고 종료합니다. 다른 서버를 미리 실행할 필요가 없습니다. `test:production`은 빌드된 dist를 4177 포트에서 별도로 실행해 높은 화질, 선미 시야, 이동 속도·설정 복원·모바일 배치를 검증합니다. 먼저 `npm run build`를 실행하세요.

```sh
CAPTURE_VIDEO=1 npm run test:browser
```

이 선택 명령은 `ffmpeg`가 설치된 환경에서 전체 항로를 48개 표본으로 캡처한 8초 영상을 추가 생성합니다. 원본 8분을 실시간 녹화한 영상은 아닙니다.

## 관람

- **항해 시작 / 하단 재생 버튼 / Space:** 기본 속도(1배)에서 8분 가상 항해의 시작, 일시정지, 재개. 종료 후 다시 시작할 수 있습니다.
- **이동 속도:** 하단에서 0.5배·1배·1.5배·2배·4배 선택. 위치를 유지하며 이후 이동 속도와 항적·엔진음이 바뀝니다. 남은 시간은 선택한 속도를 기준으로 표시합니다(처음부터 0.5배는 16분, 4배는 2분). 일시정지·다시 시작·새로고침 후에도 선택을 유지하며, 물결과 구름의 시간은 가속하지 않습니다.
- **드래그 / 터치 드래그 / 방향키:** 같은 갑판 위치에서 둘러보기. 자유 비행을 허용하지 않아 선체·지형 관통을 제한합니다.
- **선수·도시·선미:** 갑판 관람 지점과 방향 전환.
- **낮·골든아워·야간:** 태양, 대기, 조명, 수면, 건물 창 조명의 일관된 프리셋 전환.
- **소리:** 사용자 클릭 후에만 합성 엔진·물결·바람 소리가 활성화됩니다. 실제 현장 녹음은 아닙니다.
- **설정:** 화질, 움직임 줄이기, 소리 크기와 처음부터 다시 시작.
- **항로 보기 / 풍경 이야기:** 간략한 항로와 랜드마크 해설. Escape로 닫을 수 있습니다.

브라우저가 숨겨지면 항해를 일시정지합니다. 환경설정은 기기에 저장됩니다. 모든 글꼴과 텍스처를 로컬에서 제공하므로 실행 중 외부 API나 인증 키가 필요하지 않습니다.

## 기술 선택

Three.js 0.186.1의 `WebGPURenderer`와 TSL을 사용했습니다. 같은 노드 재질을 WebGPU와 WebGL2 백엔드에서 사용할 수 있고, 도시 지오메트리·재질·환경맵·반사를 통합하기 쉽다는 이유로 선택했습니다. 원본 `web-ocean`의 독립 WebGPU 엔진을 그대로 이식하지 않았습니다.

- `src/spectrum.js`: 결정적인 난수, 유한 수심 분산, 방향성 Phillips 스펙트럼, 두 개의 64×64 역 FFT. 약 12Hz로 부동소수점 높이·기울기 텍스처를 갱신합니다.
- `src/river.js`: 선박을 따라가는 지수 분포 격자(근경 약 1m 간격), FFT 변위, 다중 스케일 미세 법선, Fresnel, 태양 하이라이트, 평면 반사, 선박 속도와 방향에 연결된 항적. 반사에 변위를 반영하는 정확한 광선 추적이나 유체 역학은 아닙니다.
- `src/world.js`: 강변·교량·63빌딩·Parc1·IFC·갑판의 절차적 모델. 재질별 병합과 수목 인스턴싱을 사용합니다.
- `src/main.js`: 렌더러 선택, 항해 상태, 카메라, 시간대와 UI. 시작·종료 구간에는 smoothstep 가감속의 적분을 적용합니다.
- `src/audio.js`: 사용자 동작 이후 활성화되는 Web Audio 합성 환경음.
- `tests/`: FFT 수치·항로 안전 여유·가감속의 단위 검증과 실제 Chromium에서 수행하는 기능·복구·반응형 검증.

화질은 내부 해상도, 반사 해상도와 그림자 사용을 조절합니다. **자동 동적 해상도, 도시의 다단계 LOD, KTX2 파이프라인, GPU FFT, 실제 차량·열차 시뮬레이션은 구현하지 않았습니다.**

## 재현 가능한 관찰

다음 URL 매개변수는 개발·검증용입니다. 일반 관람 UI에서는 노출하지 않습니다.

| 매개변수   | 예                        | 설명                                                           |
| ---------- | ------------------------- | -------------------------------------------------------------- |
| `time`     | `golden`, `day`, `night`  | 초기 시간대                                                    |
| `view`     | `city`, `bow`, `stern`    | 초기 갑판 방향                                                 |
| `progress` | `0.42`                    | 항해 시각의 비율, 0–1. 가감속이 반영된 거리 비율과는 다릅니다. |
| `quality`  | `high`, `balanced`, `low` | 초기 품질                                                      |
| `backend`  | `webgl`                   | WebGL2 강제 사용                                               |
| `backend`  | `webgpu`                  | 소프트웨어 어댑터 감지를 무시하는 WebGPU 진단용 옵션           |
| `still`    | `1`                       | FFT·구름·선박 흔들림의 장면 시간을 고정.                       |
| `ui`       | `0`                       | UI와 비네트를 숨긴 장면 캡처                                   |
| `rate`     | `120`                     | 최대 120배 항해 가속, 전체 항로 검증용                         |

`window.__HAN_RIVER__`는 검증용 상태·측정값과 시점·시간대 제어를 제공합니다. 프레임 시간은 CPU 애니메이션 콜백 간격이며 GPU timestamp 측정값이 아닙니다. 초기 로딩과 첫 프레임까지의 시간은 별도 기록합니다.

## 품질 한계와 다음 단계

현재 모델의 정확성·시각 품질은 [지리와 자산 범위](docs/GEOGRAPHY.md), 실제 실행 결과는 [검증 보고서](docs/VALIDATION.md)를 참고하세요. 우선순위는 다음과 같습니다.

1. 라이선스가 확인된 서울 GIS·정사영상·건물 자료로 지형과 교량 위치, 건축물 비례를 교정하고 실제 사진과 동일 시점에서 검증.
2. 근경 교량·갑판·랜드마크의 고품질 PBR 자산과 실제 녹음 환경음 도입.
3. GPU FFT, 반사 거칠기 필터링, 교각 주변 물결과 접촉 그림자, 다단계 LOD·공간 분할·압축 텍스처.
4. 실제 GPU에서 1920×1080, 60fps의 프레임 예산을 측정하고 최적화. 현재 클라우드 결과만으로 달성을 주장하지 않습니다.
